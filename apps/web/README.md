# AnimeKaiser Web App

The AnimeKaiser web application. It provides the browser experience for anime discovery, user profiles, libraries, synchronization activity, watch history, and streaming.

## Development

```bash
bun run dev
```

The app is served at `http://localhost:3000`. Shared components come from `@animekaiser/ui`, and shared client contracts come from `@animekaiser/domain`.
